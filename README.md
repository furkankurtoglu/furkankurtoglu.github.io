# Furkan Kurtoglu - personal website

A dependency-free academic portfolio with selected publications, research projects, background, personal interests, and contact links.

## Preview locally

Run `python -m http.server 4173 --bind 127.0.0.1` from this directory and open http://127.0.0.1:4173.

## Files

- `index.html`: website content.
- `styles.css`: shared responsive styles.
- `academic.css`: Classic Academic layout and portrait framing.
- `script.js`: research / applied AI filter and footer year.
- `assets/furkan-kurtoglu.jpg`: profile photo.
- `favicon.svg`: site icon.
- `.nojekyll`: static GitHub Pages support.

No installation or build step is required. Relative asset paths support both GitHub user pages and repository pages. Google Fonts has local fallback fonts.

## GitHub Pages

In repository Settings > Pages, choose Deploy from a branch, select the published branch and / (root).
